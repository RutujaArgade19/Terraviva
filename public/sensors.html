Choose UTF-8 CSV or JSON, up to 256 KiB and 500 readings. Every row must validate before the batch is stored.

No file selected.

Required fields and format

id, deviceId, field, observedAt, measurement, value, unit; optional quality.

JSON accepts an array or {"readings": [...]}. Quote numeric values to keep their exact formatting. CSV uses these field names as headers.

A batch may contain several demo devices. Real gateway batches are limited to the device enrolled for that gateway.

The demo does not send these rows to a server.
